# Psysia ReaWebAPI fork

Upstream: https://github.com/zaibuyidao/ReaWebAPI

The main branch mirrors upstream without local patches. The default psyreasfx branch carries synchronization automation and merges upstream without force pushes. The sync workflow runs twice per hour and can be dispatched manually.

Windows release bundles and DLLs are unmodified upstream artifacts verified against GitHub SHA-256 digests. Matching source archives, licenses and a mirror manifest preserve provenance. No runtime patch or native PsyReaSFX acceptance is implied by mirroring.
